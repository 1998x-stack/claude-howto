# 代码审查清单

## 安全性检查清单
- [ ] 无硬编码的凭据或密钥
- [ ] 对所有用户输入执行输入验证
- [ ] 防止 SQL 注入（使用参数化查询）
- [ ] 在状态变更操作中启用 CSRF 防护
- [ ] 通过恰当的转义防止 XSS 攻击
- [ ] 在受保护的端点上执行身份认证检查
- [ ] 在资源访问时执行权限授权检查
- [ ] 使用安全的密码哈希算法（如 bcrypt、Argon2）
- [ ] 日志中不记录敏感数据
- [ ] 强制使用 HTTPS

## 性能检查清单
- [ ] 无 N+1 查询问题
- [ ] 合理使用数据库索引
- [ ] 在合适场景下实现缓存机制
- [ ] 主线程上无阻塞操作
- [ ] 正确使用 async/await
- [ ] 大型数据集已分页处理
- [ ] 数据库连接已使用连接池管理
- [ ] 正则表达式已优化
- [ ] 无不必要的对象创建
- [ ] 已预防内存泄漏

## 质量检查清单
- [ ] 函数长度小于 50 行
- [ ] 变量命名清晰明确
- [ ] 无重复代码
- [ ] 具备恰当的错误处理机制
- [ ] 注释说明“为什么”（WHY），而非“做什么”（WHAT）
- [ ] 生产环境中无 console.log 输出
- [ ] 启用类型检查（TypeScript / JSDoc）
- [ ] 遵循 SOLID 设计原则
- [ ] 设计模式应用正确
- [ ] 代码具备自解释性（Self-documenting）

## 测试检查清单
- [ ] 已编写单元测试
- [ ] 已覆盖边界情况
- [ ] 已测试错误场景
- [ ] 已包含集成测试
- [ ] 测试覆盖率 > 80%
- [ ] 无不稳定（flaky）测试
- [ ] 外部依赖已正确模拟（mock）
- [ ] 测试名称清晰易懂
