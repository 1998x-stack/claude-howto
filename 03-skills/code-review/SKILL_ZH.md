# 代码审查技能

本技能提供全面的代码审查能力，重点关注以下四大维度：

1. **安全性分析**
   - 身份认证与授权问题
   - 数据暴露风险
   - 注入类漏洞（如 SQL 注入、命令注入等）
   - 密码学实现弱点（如弱随机数、过时加密算法）
   - 敏感数据日志记录（如密码、令牌明文输出）

2. **性能审查**
   - 算法效率分析（含时间/空间复杂度 Big O 评估）
   - 内存使用优化（如对象泄漏、冗余拷贝）
   - 数据库查询优化（如 N+1 查询、缺失索引、全表扫描）
   - 缓存策略建议（如适用场景、缓存失效机制）
   - 并发问题（如竞态条件、死锁、线程安全缺陷）

3. **代码质量**
   - SOLID 面向对象设计原则遵循情况
   - 设计模式应用合理性（如过度设计或缺失关键模式）
   - 命名规范性（变量、函数、类命名是否清晰、一致、符合语言惯例）
   - 文档完整性（含函数注释、模块说明、API 文档覆盖度）
   - 测试覆盖率与测试质量（单元测试、集成测试的充分性与可维护性）

4. **可维护性**
   - 代码可读性（逻辑清晰度、缩进与空格一致性、控制流易理解性）
   - 函数粒度（单个函数建议不超过 50 行）
   - 圈复杂度（Cyclomatic Complexity）评估与简化建议
   - 依赖管理（第三方库版本合理性、循环依赖、未使用依赖）
   - 类型安全性（如 TypeScript 类型完整性、Python 类型提示覆盖率、空值处理健壮性）

## 审查模板

对每段被审查的代码，需按以下结构输出结果：

### 概要
- 整体质量评分（1–5 分制，5 分为最优）
- 关键问题总数
- 推荐优先处理的问题类别（如“高危安全漏洞”或“严重性能瓶颈”）

### 致命问题（如存在）
- **问题描述**：简洁明确的问题定义
- **位置**：文件路径及具体行号（例如：`src/utils/auth.ts:42`）
- **影响说明**：该问题可能导致的实际后果（如权限绕过、服务崩溃、数据泄露）
- **严重等级**：Critical（致命）/ High（高）/ Medium（中）
- **修复建议**：附带可直接应用的代码示例（含前后对比）

### 分类问题清单

#### 安全性问题（如存在）
逐条列出发现的安全漏洞，并附上下文代码片段及修复说明。

#### 性能问题（如存在）
逐条列出性能缺陷，并提供对应的时间/空间复杂度分析（如“当前嵌套循环导致 O(n²) 时间复杂度，建议改用哈希查找优化至 O(n)”）。

#### 代码质量问题（如存在）
逐条列出违反代码质量规范的问题，并给出重构建议（如“将重复逻辑提取为独立函数”、“为 `calculateTotal()` 添加 JSDoc 注释说明参数与返回值”）。

#### 可维护性问题（如存在）
逐条列出影响长期可维护性的缺陷，并提出具体改进建议（如“将硬编码字符串 `'user_role'` 提取为常量”、“拆分 `processPayment()` 中超过 60 行的业务逻辑”）。
