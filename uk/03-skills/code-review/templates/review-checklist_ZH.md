# 代码审查检查清单

## 安全性检查清单
- [ ] 无硬编码的凭据或密钥
- [ ] 对所有用户输入数据进行校验
- [ ] 防御 SQL 注入（使用参数化查询）
- [ ] 对状态变更操作实施 CSRF 防护
- [ ] 通过正确的转义机制防御 XSS 攻击
- [ ] 受保护端点上执行身份认证检查
- [ ] 对资源访问执行权限校验（授权检查）
- [ ] 密码采用安全哈希算法（如 bcrypt、argon2）
- [ ] 日志中不记录敏感数据
- [ ] 强制使用 HTTPS

## 性能检查清单
- [ ] 无 N+1 查询问题
- [ ] 正确使用数据库索引
- [ ] 在合适场景下实现了缓存机制
- [ ] 主线程中无阻塞式操作
- [ ] 正确使用 async/await
- [ ] 大数据集已实现分页处理
- [ ] 数据库连接池已配置并启用
- [ ] 正则表达式已优化
- [ ] 无不必要的对象创建
- [ ] 已预防内存泄漏

## 质量检查清单
- [ ] 函数长度小于 50 行
- [ ] 变量命名清晰易懂
- [ ] 无重复代码（DRY 原则）
- [ ] 错误处理逻辑完备合理
- [ ] 注释说明“为什么”（WHY），而非仅描述“做什么”（WHAT）
- [ ] 生产环境中无 `console.log` 输出
- [ ] 已进行类型检查（TypeScript / JSDoc）
- [ ] 遵循 SOLID 设计原则
- [ ] 设计模式应用恰当
- [ ] 代码具备自解释性（Self-documenting）

## 测试检查清单
- [ ] 已编写单元测试
- [ ] 边界条件均已覆盖
- [ ] 错误场景已进行测试
- [ ] 已包含集成测试
- [ ] 测试覆盖率 > 80%
- [ ] 无不稳定（flaky）测试
- [ ] 外部依赖已通过 Mock 进行隔离
- [ ] 测试用例命名清晰明确
