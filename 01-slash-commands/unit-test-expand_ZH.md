# 扩展单元测试

基于项目所用测试框架，扩展现有单元测试：

1. **分析覆盖率**：运行覆盖率报告，识别未覆盖的分支、边界情况及低覆盖率区域  
2. **识别缺口**：审查代码中的逻辑分支、错误路径、边界条件、空值/空输入等  
3. **使用项目框架编写测试**：
   - Jest/Vitest/Mocha（JavaScript/TypeScript）  
   - pytest/unittest（Python）  
   - Go testing/testify（Go）  
   - Rust 测试框架（Rust）  
4. **聚焦特定场景**：
   - 错误处理与异常  
   - 边界值（最小/最大值、空值、null）  
   - 边界情况与极端情况  
   - 状态转换与副作用  
5. **验证改进效果**：再次运行覆盖率检查，确认覆盖率有可衡量的提升  

仅输出新增的测试代码块。严格遵循现有测试模式与命名规范。
